# Vue 3 Frontend Framework Skill

When generating Vue.js frontend applications, components, or stores:

## Key Guidelines
1. **Composition API (`<script setup>`)**:
   - Write Single File Components (`.vue`) using `<script setup lang="ts">`.
   - Use `ref()`, `reactive()`, `computed()`, and `watch()` for reactive state.

2. **State Management & Routing**:
   - Use Pinia (`defineStore`) for global state management instead of Vuex.
   - Configure Vue Router (`vue-router`) with typed route definitions.

3. **Component Structure**:
   - Keep `<script setup>`, `<template>`, and `<style scoped>` clearly structured.

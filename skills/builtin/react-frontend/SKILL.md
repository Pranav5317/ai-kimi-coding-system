# React Frontend Development Skill

When building or updating web user interfaces, adhere to these UI/UX guidelines:

## Key Guidelines
1. **Component Design**:
   - Use clean, functional components with explicit props interfaces.
   - Keep component files modular and scoped to specific UI responsibilities.
2. **State Management**:
   - Use `useState` and `useEffect` for local state and side-effects.
   - Prevent unnecessary re-renders by wrapping heavy computations in `useMemo`.
3. **API Integration**:
   - Handle loading, error, and success states explicitly for all asynchronous fetch operations.
   - Display clear feedback toasts or badges when actions fail.
4. **Responsive Styling**:
   - Apply clean CSS flexbox/grid layout math without arbitrary pixel hardcoding.
